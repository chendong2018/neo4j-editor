关于图数据服务

GraphDataService 是一个前端图数据管理服务，提供以下核心功能：

节点管理

  • 添加、获取、删除节点
  • 根据属性和标签查找节点
  • 节点唯一性验证

关系管理

  • 添加、获取、删除关系
  • 查询节点的入边和出边
  • 按属性排序关系

索引系统

  • 节点关系索引
  • 关系类型索引
  • 高效的图查询

工具函数

  • ID生成
  • 节点/关系验证
  • 对象克隆

使用示例

// 创建服务实例 const graphService = new GraphDataService(); // 添加节点 const node = { id: 'user1', labels: ['User'], properties: { name: '测试用户' } }; graphService.addNode(node); // 添加关系 const rel = { type: 'KNOWS', startNodeId: 'user1', endNodeId: 'user2', properties: { since: 2024 } }; graphService.addRelationship(rel); // 查询数据 const userRelationships = graphService.getRelationshipsByNodeId('user1');
